# 올려도 되는 것 / 안 되는 것

이 저장소는 공개 전용이다. 회사·학교 저장소와 섞지 않는다. 애매하면 올리지 않는다.

## 올려도 되는 것 (조건부)
| 대상 | 조건 |
|---|---|
| 해커톤 결과 (FactoryPulse, HackPrinceton) | **코드 복사 금지.** 원 저장소(이미 공개) 링크 + 본인 역할 3줄만 적는다. 역할 요약에 팀원 실명을 넣지 않는다. 대회 규정상 문제없는지 확인. |
| balance-forge의 공개 가능 부분 | 회사 코드이므로 기술 검수를 거치고 저장소 주인이 확인한 부분만. |
| 지난 학기 과제 | 담당 교수·과목 규정이 공개를 허용한 것만. |
| 작은 도구, 글, 학습 노트 | 직접 쓴 것. 남의 코드는 라이선스 확인 후 출처 표기. |

## 올리면 안 되는 것
- 회사 게임 플랫폼 코드와 내부 설계 (코드명은 로컬 금지어 목록에 있음)
- 회사 미공개 세계관 자료 (설정집·기획서)
- AI 에이전트 설정 파일, 권한 지도, 내부 메모
- 개인정보: 실명 외 연락처, 주소, 학번, 계정, 로컬 경로 (`/Users/...` 등)
- 학생 자료 (LA 활동 중 본 학생 과제·성적 등)
- **현재 수강 중인 과목의 과제** (학업 정직성)
- 회사 저장소 코드 원문
- 비밀값 (API 키, 토큰, 비밀번호, `.env`), 5MB 넘는 파일

## 첫 push 전 절차
1. `bash tools/install-hooks.sh`로 커밋 전 검사 훅을 켠다. `tools/blocklist.txt`에 금지어를 채운다.
2. 올릴 파일 목록을 기술 담당(토니)과 비서실(유즈)이 이 문서와 대조한다.
3. 저장소 주인이 GitHub 저장소를 만들고 직접 push한다.
